# Montre — Salla theme

Custom Salla (Twilight) theme for Montre, built on Salla's open-source Raed theme (MIT).
Design follows montrebahrain.com: charcoal, bronze and warm off-white; Jost + IBM Plex Sans Arabic.

Homepage sections (editable in the Salla theme editor): brand strip, category tiles, product rows,
pre-order banner, about, trust cards. Header and footer are restyled; product cards show the
immediate/pre-order badge, brand, title and price.

Build: `pnpm install && pnpm run production` (outputs to `public/`, which is committed).
